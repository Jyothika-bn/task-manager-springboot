# Task Manager System (Spring Boot)

A backend application built using Spring Boot that allows users to manage tasks efficiently with authentication and REST APIs.

## 🚀 Features
- User registration & login (authentication)
- Create, update, delete tasks
- Task status tracking (pending, completed)
- RESTful API design
- Exception handling & validation

## 🛠 Tech Stack
- Java
- Spring Boot
- MySQL
- JPA / Hibernate
- REST APIs

## 📌 API Endpoints
- POST /register
- POST /login
- GET /tasks
- POST /tasks
- PUT /tasks/{id}
- DELETE /tasks/{id}

## ⚙️ How to Run
1. Clone the repo
2. Open in IntelliJ / VS Code
3. Configure MySQL DB
4. Run Spring Boot application
